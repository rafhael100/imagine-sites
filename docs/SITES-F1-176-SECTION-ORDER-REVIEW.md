# F1-176 — Prévia das seis disposições da página na revisão Laravel

A equipe Imagine agora consegue conferir visualmente as seis disposições permitidas das seções Soluções, Como funciona e Perguntas frequentes, mantendo tema, produto e dispositivo. A nova rota /_lab/sites/v1/section-order é exclusivamente de testes em PHP CLI + APP_ENV=testing + IP de loopback, com flags explícitas. A rota é inerte e não é registrada em servidores HTTP.

A classe SyntheticStructuredDraftAssembly recebe uma ordenação opcional separada de qualquer texto gerado por IA. O SiteBrief valida a permutação. O código de cópia sites.ai-copy.v4 não possui permissão para selecionar ordem; esta seleção vem de um mapa fixo do motor. A interface utiliza tabs acessíveis para cada combinação e mostra o HTML exato em iframe sandbox, SHA-256, dossiê e revisão pendente.

Cada produto (Onepage/Landing) × tema (Classic/Modern/Warm) × ordem gera conteúdo e digest próprios. Em desktop/mobile os bytes de um mesmo artefato não variam. Toda composição permanece publishable=false e officialClientAcceptance=false. Os navegadores e modalidades antigas não recebem essa configuração automaticamente.

A suíte Laravel PHP 8.3/8.4 verifica 72 visualizações, integridade SHA-256, ordem real dos elementos DOM, headers de privacidade/noindex/CSP, seletores, isolamento por parâmetros, bloqueio de IP externo e flags ausentes. Este é um visualizador fictício, não editor de cliente nem aprovação operacional. OP01/02/04 e os dez gates continuam bloqueados.
