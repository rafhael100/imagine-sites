# F1-89 — Prova real de bytes HTTP servidos em servidor local descartável

A issue operacional [SITES-OP03 #35](https://github.com/rafhael100/imagine-sites/issues/35) estabelece que um HTTP **202 Accepted**, sucesso de um comando de publicação ou resposta de provedor não comprova que os bytes corretos estejam realmente acessíveis no domínio. A F1-89 implementa um **primeiro exercício real de observação HTTP** sem acessar Cloudflare, DNS ou público.

`LabLoopbackServedArtifactObserver::observe` realiza uma conexão TCP direta a `127.0.0.1` somente entre as portas 1024–65535, aceita apenas sete caminhos fixos de laboratório, usa PHP CLI com `SITES_F89_LOOPBACK_LAB=1` e faz um GET HTTP com `Connection: close`. A resposta deve ter status **200**, tamanho declarado correto, content-type HTML UTF-8, `Cache-Control: no-store`, `X-Robots-Tag: noindex`, `nosniff`, CSP restritiva e o HTML inerte exato com SHA-256 igual ao manifesto de release esperado. Redirecionamentos não são seguidos. Respostas acima do tamanho permitido ou incompletas são recusadas.

O teste `tests/f89-loopback-served-artifact.php` inicia um servidor PHP descartável em endereço **loopback**, gera conteúdo 100% fictício pelo renderer e observa os bytes de fato servidos. Também comprova que status 202, 302, 404, HTML obsoleto, headers de segurança ausentes, content-type incorreto, digest de release divergente, caminho arbitrário, URL externa, porta privilegiada e modo não autorizado são rejeitados. O servidor e os arquivos temporários são descartados após a execução; a matriz é repetida em PHP 8.3 e 8.4 pelo CI.

**Limitações essenciais:** esta verificação só opera na mesma máquina e não se conecta a outro hostname: não prova propagação de CDN, TTL, TLS/certificado, cache de borda, funcionamento público, autoridade do domínio ou observação independente fora do processo de deploy. A verdadeira comprovação exigirá um observador externo autorizado com HTTPS, autenticidade e políticas contra SSRF, mais comparação do HTML servido com a release exata, consentimento do titular, quota, trilha e rollback **manual**. Não existe chave de Cloudflare, upload, nova despesa ou modificação de ambiente. Os dez gates operacionais continuam `BLOCKED`.
